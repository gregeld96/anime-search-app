Project: Anime Search (React + TypeScript SPA)

Build a complete SPA using:
- React 18+ + TypeScript
- TailwindCSS
- Redux Toolkit
- TanStack Query
- React Router DOM
- Custom React Hooks Component Level
- npm ONLY

Requirements:
- Must use Vite
- Dev server must run on port 4000
- Two pages:
    / → List Search Page
    /anime/:id → Anime Detail Page
- Search query should be stored in Redux
- API should use TanStack Query (Jikan API)

Use modular architecture:
src/
  pages/
  components/
  hooks/
  store/
  api/
  types/
