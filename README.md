## AnimeSearch - Modern Anime Discovery App

AnimeSearch is a modern, responsive web application for discovering and exploring anime. Built with cutting-edge web technologies, it offers a seamless and engaging user experience for anime enthusiasts.

## Core Stack
- React 18 - Modern React with hooks only
- TypeScript - Type-safe development
- Redux Toolkit - State management
- React Router DOM - Client-side routing
- Tailwind CSS - Utility-first styling
- Framer Motion - Smooth animations

## Development Tools
- Vite - Fast build tool and dev server
- React Testing Library - Unit and integration tests

## Core Features
- Instant Search: Real-time anime search with intelligent debouncing
- Redux State Management: Manage states within the app

## Bonus Implementation
- Creative UI with unique "wow" factor
    - Infinite Scroll: Seamless pagination for endless browsing
    - Responsive Design: Perfect experience across all devices
    - Dark/Light Mode: Toggle between themes for comfortable viewing
- Loading Skeleton
- Mobile Responsiveness
- Favorites mechanism which store at the state management

- Proper Handling for (network failures, rate limiting, invalid API responses)
- Integration Jest Test
